# A VOID DANCER — プレイテスト

**[ブラウザでプレイ](https://lunachil32.github.io/dancer-playtest/)**

PCとキーボードで遊ぶWebGL版です。まずは「チュートリアル」からどうぞ。
初回は音を出す前に音量設定を選べます。「音量を設定する」を選んだ場合は、全体とBGMの両方の音量を上げてください。

## 操作

| 操作 | 初期キー |
| --- | --- |
| メニュー選択・移動 | 矢印キー |
| 決定 | Enter |
| 戻る・ポーズ | Esc |
| リズム攻撃 | Q → W → E → R |
| ステップ | Space |
| インタラプト | 左Shift |

キー・音量・入力タイミングはオプションで変更できます。
設定と進行はブラウザ内に保存されます。ブラウザを変えたり、サイトの保存データを消した場合は引き継がれません。

音が出ない場合はゲーム画面をクリックし、ブラウザの音声許可とゲーム内の全体/BGM音量をご確認ください。
